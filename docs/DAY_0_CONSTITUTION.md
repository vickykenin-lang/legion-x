# LEGION-X Day-0 Constitution

## Fixed Objective

Build a highly automated, free-first short-video content business focused on original, family-friendly:

- Cartoon mini-stories
- Tiny-toy and miniature-world stories
- Fictional AI baby reactions
- Cute animal reaction stories
- Funny and emotional reels

## Initial Operating Target

| Item | Target |
| --- | --- |
| Content brands | 1 |
| Original reels | 3 per day |
| Monthly originals | 90 |
| Platforms | YouTube Shorts, Facebook Reels, Instagram Reels |
| Maximum monthly uploads | 270 |
| Reel duration | 15–25 seconds |
| Format | 1080 × 1920 MP4, 9:16 |
| Initial software/API budget | ₹0 |
| Human role | Approval, QA, exception handling |

## Required Business Loop

`Idea → Script → Prompt → Visuals → Video → Voice/SFX → Editing → QA → Metadata → Publishing → Analytics → Learning → Next Content`

## Strategic Rules

1. Build recognizable original characters and repeatable formats.
2. Do not build around downloaded, reposted, or random viral clips.
3. Prefer fictional AI-generated children over real children's footage.
4. One working end-to-end pipeline must be proven before scaling.
5. Failed Guardian checks always enter manual review.
6. Money is spent only after real performance data proves a bottleneck.
7. Winning formats are replicated with meaningful variations; weak formats are stopped.
8. Platform policy, originality, copyright, and children's-content requirements override publishing volume.

## Primary Success Metric

Find at least one repeatable format that consistently produces above-average reach and retention.

## Scope Control

This document is the fixed Day-0 baseline. Execution methods, models, providers, and technical components may improve, but they must not silently change the core objective.
