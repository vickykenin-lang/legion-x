# Chiku — Master Character Bible

## Role

Chiku is LEGION-X's first permanent hero: a brave, curious, kind, clever, and playful little chick for original family-friendly short stories.

## Locked Visual Identity

| Attribute | Specification |
| --- | --- |
| Species | Small chick |
| Body | Soft, rounded, golden-yellow body |
| Eyes | Slightly oversized, expressive warm-brown eyes |
| Beak | Tiny orange beak |
| Feet | Short orange feet |
| Head mark | One upward-curving feather tuft |
| Signature accessory | Teal-blue neck scarf |
| Hero symbol | Small golden star clasp on scarf |
| Overall style | Premium stylized 3D children's animation |
| Proportions | Large round head, compact round body, short wings and legs |

## Personality Rules

- Brave without aggression
- Curious without recklessness
- Kind and helpful
- Clever problem solver
- Playful reactions
- Never cruel, frightening, or sarcastic

## Consistency Locks

Every generated Chiku scene must preserve:

1. Golden-yellow feather colour.
2. Warm-brown eye colour and rounded eye shape.
3. Single upward-curving feather tuft.
4. Teal-blue scarf with golden star clasp.
5. Orange beak and feet.
6. Rounded child-friendly proportions.
7. No trousers, shirt, shoes, hat, or additional accessories unless a story exception is explicitly approved.
8. No resemblance to an existing copyrighted cartoon character.
9. No text, logos, or watermarks inside scene images.

## Core Expressions

- Happy
- Surprised
- Determined
- Worried
- Caring
- Celebrating

## Reference Prompt

Create the same exact Chiku: a very cute small golden-yellow chick with a round soft body, slightly oversized expressive warm-brown eyes, a tiny orange beak, short orange feet, one distinctive upward-curving feather tuft, and a teal-blue neck scarf with a golden star-shaped clasp. Premium original stylized 3D children's animation, soft feather detail, rounded proportions, family-friendly, consistent identity.

## First Pilot Direction

Working concept: **Chiku and the Fallen Star**

A magical glowing star falls into Chiku's nest. Chiku notices that it is scared, attempts a funny rescue, and helps it return to the sky. The ending loops when another tiny sparkle begins falling.
