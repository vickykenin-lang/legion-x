# LEGION-X

**Autonomous Content Command Engine**

> Many Powers. One Mission.

LEGION-X is a free-first automation system for building an original short-form content business across YouTube Shorts, Facebook Reels, and Instagram Reels.

## Day-0 Mission

- One original content brand
- Three original reels per day
- 15–25 second vertical videos (9:16)
- YouTube, Facebook, and Instagram distribution
- Initial software/API budget: ₹0
- Human role: approval, quality control, and exception handling

## Agent Legion

| Agent | Responsibility |
| --- | --- |
| Oracle | Trends, research, and content ideas |
| Scripter | Hooks, stories, scripts, and scenes |
| Forge | Visuals, voice, sound, and video assembly |
| Guardian | Technical, originality, safety, and policy QA |
| Flash | Scheduling and multi-platform publishing |
| Vision | Analytics and performance scoring |
| Phoenix | Improved variations of proven winners |

## Core Loop

`Research → Create → Publish → Measure → Learn → Improve → Monetize → Scale`

## Status

Foundation phase in progress. The attached Automated Short-Reel Business Plan is the fixed Day-0 baseline. The first milestone is one complete working pipeline before scaling.

## Operating Principles

1. Free/open/local tools first.
2. Original characters and stories, not reposted content.
3. No automatic publishing without passing Guardian QA.
4. Secrets never enter the repository.
5. Generated media stays outside Git; only code, prompts, workflows, and documentation are versioned.
6. Scale only after real audience data proves a repeatable format.
