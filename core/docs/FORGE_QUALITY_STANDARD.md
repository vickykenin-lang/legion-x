# Forge Quality Standard

No LEGION-X reel is publish-ready unless Guardian confirms all of the following:

| Requirement | Threshold |
| --- | --- |
| Actual motion | Character, camera, or environment changes—not a static slideshow |
| Opening | Visible pattern break in first two seconds |
| Narration | Voice-over present and understandable |
| Sound | Licensed/original music or SFX present |
| Pacing | Average shot length 2.5 seconds or below |
| Visual beats | At least 8 changes in a 15–25 second reel |
| Captions | Present and inside safe area |
| Format | 1080 × 1920 MP4 |
| Watermark | None from a generation provider |

## Hard Rejection Conditions

- Static slideshow
- Missing voice-over
- Provider watermark
- Missing sound design
- Weak first-two-second hook

The old Chiku pilot is intentionally classified as **REJECTED**. It is a technical assembly proof, not a creative benchmark.
